AI 新闻简报生成工具
一款自动抓取主流新闻网站标题，通过本地 Ollama 模型生成结构化中文新闻简报，并保存到桌面的工具。
功能特点
📰 多源新闻抓取：自动从新浪新闻、新浪财经、网易科技、中国新闻网抓取新闻标题
🧠 AI 智能总结：基于 Ollama 本地模型生成分类清晰的新闻简报
📁 自动保存：生成的简报以 Markdown 格式保存到桌面，文件名包含日期
🔍 内容净化：自动过滤广告、登录等无关内容，去重并筛选有效标题
📋 结构化输出：严格按国内要闻、国际新闻、财经市场、科技动态、社会民生五大类生成
环境要求
1. 软件依赖
Python 3.7+
本地部署的 Ollama 服务（需启动并运行）
下载指定模型：gemma4:latest（可在代码中修改为其他模型）
2. Python 库安装
bash
运行
pip install requests beautifulsoup4

1. 启动 Ollama 服务
确保本地 Ollama 服务已启动，默认端口 11434（无需修改，代码已适配）：
bash
运行
ollama serve
2. 下载模型
bash
运行

3. 运行脚本
bash
运行

4. 查看结果
运行完成后，桌面会生成名为 AI完整新闻简报_YYYY-MM-DD.md 的文件，打开即可查看结构化新闻简报。
代码结构说明
表格
函数名	功能描述
get_news()	抓取各新闻源标题，过滤净化后返回去重的标题列表
summarize(news)	构造提示词，调用 Ollama API 生成分类新闻简报
save(content)	将生成的简报保存为 Markdown 文件到桌面
自定义配置
修改模型：修改代码中 OLLAMA_MODEL 变量，替换为你本地的其他 Ollama 模型（如 llama3:latest）
调整新闻源：修改 sources 列表，添加 / 删除新闻网站 URL
调整输出格式：修改 summarize 函数中的 prompt 内容，可调整分类数量、每条字数、分类名称等
调整标题筛选规则：修改 get_news 函数中标题长度判断（8 < len(title) < 40）
注意事项
确保网络畅通，能正常访问新闻网站
Ollama 服务需保持运行状态，否则无法生成简报
部分新闻网站可能有反爬机制，若抓取失败会自动跳过该源
生成的简报内容完全基于抓取的新闻标题，AI 不会编造内容
建议定期更新模型以获得更好的总结效果
